# XML-сервис: обработка и загрузка XML документа

Веб-сервис для загрузки XML-документов с валидацией по XSD-схеме
и сохранением данных в базу данных.

## Задача (по ТЗ)

Разработка сервиса загрузки XML документа с записью данных в базу данных.
При загрузке проводится проверка на корректность составления XML файла,
при несоответствии — выдаются ошибки.

## Стек

- **Python 3.12**
- **lxml** — парсинг и валидация XML по XSD
- **SQLAlchemy** — ORM для работы с БД
- **SQLite** — база данных (файл `books.db`, на этапе разработки без Docker)
- *(планируется)* **FastAPI** — веб-сервис / REST API
- *(планируется)* **pytest** — автотесты

## Модули: что делает каждый файл

### `app/logger.py`
Настраивает единый логгер на весь проект. Пишет одновременно в консоль и в
`logs/app.log`. Используется во всех остальных модулях через
`logger = setup_logger(__name__)`.

### `app/validator.py`
- Загружает XSD-схему из `app/schemas/books.xsd` один раз при импорте модуля.
- `validate_xml(xml_bytes: bytes) -> etree._Element` — парсит и валидирует XML.
  - Кидает `XMLValidationError` с списком ошибок (`.errors`), если XML не
    well-formed ИЛИ не соответствует схеме.
  - Различает две категории ошибок: синтаксические (`XMLSyntaxError`) и
    ошибки соответствия схеме (`_schema.error_log`).

### `app/models.py`
SQLAlchemy-модель `Book` — таблица `books` с полями `id`, `name`, `author`,
`publish_date`.

### `app/db.py`
- `DATABASE_URL` — путь к SQLite-файлу (`sqlite:///./books.db`).
- `init_db()` — создаёт таблицы, если их ещё нет.
- `SessionLocal` — фабрика сессий для работы с БД.

### `app/repository.py`
- `parse_books_from_xml(root)` — превращает провалидированное XML-дерево в
  список объектов `Book`. Использует namespace `http://mephi3.ru` при поиске
  элементов.
- `save_books(session, books)` — сохраняет список книг одной транзакцией,
  откатывает при ошибке.

## Как запустить тесты вручную

```bash
python test_validator_manual.py       # проверка валидатора (3 сценария)
python test_db_manual.py              # проверка создания таблицы
python test_full_pipeline_manual.py   # полный цикл: XML -> БД
```

## Известные особенности окружения (чтобы не наступать на те же грабли)

- Используйте venv-интерпретатор проекта (`.venv\Scripts\python.exe`), а не
  Windows Store alias `python.exe` (он даёт sandboxed доступ к файловой
  системе и ломает относительные/абсолютные пути к файлам на других дисках).
- В Git Bash пути указываются через `/`, а не `\` — обратный слэш
  экранирует символы.
